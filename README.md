# Loops - Java Project

A Java project featuring a classic Snake game and loop-based utilities, developed as a learning exercise.

## Overview

This repository contains:
- **Snake Game**: A graphical game where you control a snake to eat food, grow, and avoid collisions.
- **Loop Utilities**: Additional Java programs demonstrating loop concepts, such as prime number calculations.

## Files

- `src/app.java`: Entry point for the Snake game, sets up the game window.
- `src/Main.java`: Core Snake game logic, handling movement, rendering, and game mechanics.
- `src/primeNumber.java`: Utility for prime number-related operations.
- `.gitignore`: Excludes IntelliJ IDEA files and other unnecessary items.
- `LICENSE`: MIT License for open-source usage.
